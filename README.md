# Security Work Samples

A collection of cybersecurity projects, lab work, technical reports, and supporting verification from my academic and professional development in cybersecurity.

The repository primarily focuses on **penetration testing, Active Directory security, malware analysis, reverse engineering, OSINT, and vulnerability research**.

## Repository Contents

### 📁 GOAD Penetration Testing Labs & Reports

Hands-on penetration testing work performed against the **Game of Active Directory (GOAD)** intentionally vulnerable lab environment.

Topics covered include:

- Active Directory enumeration
- AS-REP Roasting and Kerberoasting
- NTLM relay attacks
- BloodHound attack-path analysis
- LDAP and PowerView enumeration
- Credential and hash extraction
- Pass-the-Hash
- Privilege escalation
- Post-exploitation techniques

The directory contains individual lab reports as well as a comprehensive final penetration testing report.

---

### 📁 Malware Report

A detailed reverse engineering and malware analysis project covering **Agent Tesla**.

The analysis progresses through basic and advanced static and dynamic analysis using tools such as:

- IDA Pro
- x64dbg
- Wireshark
- Process Monitor
- PEview
- Strings64
- Regshot
- ApateDNS

The report documents the investigation process, observed malware behavior, indicators of compromise, and reverse engineering methodology.

### 📁 Security Work & Verification

Supporting documentation for previous cybersecurity work and security research.

This includes redacted correspondence related to:

- An authorized cybersecurity assessment for a school district
- An OSINT and metadata security assessment for a higher-education organization
- Responsible disclosure of a software vulnerability

Sensitive and unnecessary personal information has been redacted from these materials.
