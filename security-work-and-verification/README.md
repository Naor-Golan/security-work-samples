# Security Work Verification

This directory contains redacted correspondence that helps verify previous cybersecurity work and security research.

## Included

- **Bloomfield Cybersecurity Assessment** — Feedback from Bloomfield Central School District following an authorized cybersecurity assessment.
- **USHE OSINT Assessment** — Feedback from the Utah System of Higher Education following an OSINT and metadata security assessment.
- **Software Vulnerability Disclosure** — Correspondence documenting the responsible disclosure of a software vulnerability.

Personal and contact information has been redacted where appropriate.

These materials are provided solely as supporting verification of previously completed cybersecurity work.
